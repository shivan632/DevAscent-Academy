What is the exact atomic difference between REDIS SETNX and SET key val NX EX 30?

check_circle STAFF EXPLANATION

Classic SETNX requires a separate EXPIRE call. If the process crashes between them, you leak the lock indefinitely. SET NX EX executes lock creation and TTL in a single atomic C-level command.
